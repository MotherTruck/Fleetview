Deploy by name

For a one-off install that doesn't need saving to the catalog. The exact name depends on each device's platform: a pacman package name for Arch/CachyOS, an apt package name for Debian/Ubuntu, or a winget package ID for Windows. NETWORK

Server port & access

The dashboard/API port and bind address are Docker Compose settings, applied before the server process starts — the running server has no way to read or change them itself, so there's no live control for them here. They're set in this host's .env file instead:

FLEETVIEW_BIND_ADDRESS=127.0.0.1   # or a LAN/VM IP, or 0.0.0.0
FLEETVIEW_PORT=8080

After changing either value, run docker compose up -d on the Docker host to apply it. To check what's actually published right now (and diagnose access problems from another machine), run ./scripts/check-access.sh there.
